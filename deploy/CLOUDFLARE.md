# Селина на Cloudflare Pages (бесплатно)

Что это даёт и чего НЕ даёт — честно, чтобы не было сюрпризов.

## Что переезжает бесплатно и за 15 минут

**Статический фронтенд: все 128 пререндеренных страниц.** Главная, блог (50
статей), 44 города, 10 стран, лендинги, оферта. Это ~90 % трафика и весь SEO.

Что это меняет на практике: сегодня падение одного VPS гасит сайт целиком.
После переезда статики сайт остаётся ОТКРЫТЫМ и индексируемым даже при
недоступном API — не работает только то, что требует данных (лента поваров,
корзина, кабинет). Для сервиса, который живёт на поиске, это разница между
«сайт лежит» и «сайт работает, заказы временно недоступны».

Лимиты бесплатного плана Pages: запросы и трафик безлимитны, 500 сборок в
месяц. Для Селины это с большим запасом.

### Как выкатить

1. `cd frontend && VITE_SITE_URL=https://celinaeda.ru npm run build`
2. Cloudflare → Workers & Pages → Create → Pages → Upload assets → папка `frontend/dist`
   (либо подключить GitHub-репозиторий: build command `npm run build`,
   output `dist`, переменная `VITE_SITE_URL=https://celinaeda.ru`).
3. Custom domain → `celinaeda.ru` (Cloudflare сам выпустит сертификат).
4. API оставить на своём сервере под отдельным поддоменом (например
   `api.celinaeda.ru`) — он уже прописан в `frontend/public/_redirects`.

Файлы `_redirects` и `_headers` уже лежат в `frontend/public/` и попадают в
сборку автоматически.

## Что НЕ переезжает без переписывания

API — это Express + Prisma + SQLite + файловые загрузки + SSE + сигналинг
видеозвонков. На Cloudflare Workers это не «перенести», а переписать:

| Что сейчас | На Workers нужно |
|---|---|
| Express-роуты | переписать на Hono (Workers не запускают Express) |
| Prisma + SQLite-файл | D1 — у Workers нет файловой системы |
| Транзакции при заказе (списание порций) | D1 не даёт интерактивных транзакций — логику заказа переделывать |
| Загрузки на диск (KYC, фото блюд) | R2 |
| SSE и сигналинг звонков | Durable Objects |

Это дни работы, а не вечер, и переписывать пришлось бы самую денежную часть —
создание заказа.

## Отдельно: закон о персональных данных

Селина хранит паспорта и селфи-видео поваров и работает на российском рынке.
152-ФЗ требует, чтобы базы с персональными данными россиян находились в
России. Cloudflare D1/R2 — глобальные хранилища. Переносить туда БАЗУ и KYC
без консультации юриста нельзя; статика (HTML, картинки блюд, шрифты)
персональных данных не содержит и этой проблемы не создаёт.

## Вывод

- Статику — на Pages, бесплатно, сегодня. Сайт перестаёт зависеть от одного VPS.
- API и базу — оставить на сервере в России (Timeweb или другой хостинг).
- Полный переезд на Workers — отдельный проект, и он упирается не в деньги,
  а в 152-ФЗ и в переписывание оформления заказа.
